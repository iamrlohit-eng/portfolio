# Lohith Raj R — Portfolio

A responsive, dependency-free portfolio exploring data analysis, generative AI, prompt engineering, and cybersecurity.

## Run locally

Open `index.html` in a browser. No build step, package installation, or development server is required.

## Features

- Responsive layout with mobile navigation
- Interactive sample analytics dashboard with 7-day and 30-day views
- Filterable project gallery and accessible project-detail dialogs
- Contact form that prepares a message in the visitor's email app
- Reduced-motion support and keyboard-accessible controls

## Customize before publishing

- Replace `hello@lohithraj.dev` in `index.html` and `script.js` with your preferred contact email.
- Update the project descriptions and case-study details in `index.html` and `script.js` with your own work and verified outcomes.
- The dashboard uses illustrative sample data. Replace it with accurate data or label it clearly as a demo.
- Review the About section and skills to ensure they reflect your current experience.

## Files

- `index.html` — page content and structure
- `styles.css` — visual design and responsive styles
- `script.js` — chart, filters, dialogs, navigation, and contact interactions
